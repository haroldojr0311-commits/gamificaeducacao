📜 De onde vem a Torre de Hanói?

O quebra-cabeça foi apresentado em 1883 pelo matemático francês Édouard Lucas. Ele criou uma lenda para torná-lo mais interessante: um templo, em Hanói (no Vietnã), onde monges moviam 64 discos de ouro de uma torre para outra.

A lenda diz: quando os monges terminassem de mover todos os discos, o mundo acabaria.

A lenda é invenção de Lucas. Mas a pergunta matemática é real: quantos movimentos são necessários para mover 64 discos?

Quanto tempo levaria?

Para 64 discos, o número mínimo de movimentos é:

264 − 1 = 18 446 744 073 709 551 615

Se cada movimento levasse 1 segundo (sem parar, dia e noite), o total seria de cerca de 585 bilhões de anos. A idade estimada do universo é de cerca de 13,8 bilhões de anos. Ou seja, a lenda não acabaria tão cedo!

Curiosidade: esse quebra-cabeça é um exemplo clássico de problema recursivo: para resolver um caso grande, resolvemos casos menores dentro dele. Vamos ver isso na próxima aba.

🧮 A matemática por trás do jogo

Passo 1: as variáveis

  • n = número de discos na torre.
  • T(n) = número mínimo de movimentos necessários para mover n discos. Lemos “T de n”.

Passo 2: os casos mais simples

  • 1 disco: basta 1 movimento. Então T(1) = 1.
  • 2 discos: mova o pequeno para o pino auxiliar, mova o grande para o destino, depois mova o pequeno para cima dele. São 3 movimentos. Então T(2) = 3.

Passo 3: a ideia principal (recursão)

Para mover n discos, pense assim:

  1. Mova os n − 1 discos de cima para o pino auxiliar. (Isso custa T(n − 1) movimentos.)
  2. Mova o disco maior, que sobrou embaixo, para o pino de destino. (1 movimento.)
  3. Mova os n − 1 discos do auxiliar para o destino, por cima do maior. (Mais T(n − 1) movimentos.)

Por isso, a regra geral é:

T(n) = 2 · T(n − 1) + 1

Essa é uma relação de recorrência: o valor para n depende do valor para n − 1.

Passo 4: encontrando a fórmula

Calculando alguns valores: T(1) = 1, T(2) = 3, T(3) = 7, T(4) = 15, T(5) = 31…

Repare que cada valor é o dobro do anterior mais 1, e que sempre é uma unidade a menos que uma potência de 2. Isso leva à fórmula:

T(n) = 2n − 1
Verificando com a recorrência: se T(n − 1) = 2n−1 − 1, então
T(n) = 2 · (2n−1 − 1) + 1 = 2n − 2 + 1 = 2n − 1. ✔

Passo 5: o gráfico do crescimento

Veja como o número de movimentos explode quando aumentamos os discos:

Altura das barras = T(n) = 2n − 1, para n de 1 a 10. Cada disco a mais quase dobra o trabalho!

Atenção aos erros comuns

❌ “Com 4 discos são 4 · 2 − 1 = 7 movimentos.”
✅ A conta correta é 24 − 1 = 15. O crescimento é exponencial, não linear.

❌ “Com 3 discos, o disco maior precisa se mexer 3 vezes.”
✅ O disco maior se move uma única vez nessa solução ótima.
